# Package frontend RoadmapAI

Ce dossier contient l’application React/Vite et son `package.json`. La documentation complète du frontend (fonctionnalités, architecture, routes, API, design et suivi) se trouve dans le [README à la racine du dépôt](../readme.md).

## Démarrage rapide

Depuis ce dossier :

```powershell
npm install
```

Créer `.env.local` dans ce dossier avec l’URL du backend :

```env
VITE_API_BASE_URL=http://localhost:8000/
```

Puis lancer l’application :

```powershell
npm run dev
```

Commandes également disponibles : `npm run build`, `npm run lint` et `npm run preview`.
